# Prompt v5: actionability and recency (2026-11-07)

`prompts/v5.md` is `prompts/v4.md` with a "Two tests decide most of the score"
section at the top and a few rules made explicit. It was written because
`claude-haiku-5-5` and `gpt-6-luna`, the Claude and OpenAI models (PRD
`RANK-19`), ranked far below `gemini-3.8-flash` with v4. They applied v4's
rules loosely in two ways:

- **Actionability.** They scored items high when the next step wasn't the
  developer's: an issue whose fix PR is already open, after someone asked for a
  status update; a PR labelled `next-breaking-release`, after someone asked a
  question; a team review request in a repository the developer doesn't own,
  because the author is a collaborator; an item with a thumbs-down, because of
  a comment from before it.
- **Recency.** They sank the developer's own issue filed 9 days ago because
  nobody was waiting on them, and treated old activity as new.

v5 asks for the next action first, caps items the developer can't act on now
at the ranges at 0.5 or below, and uses the ages in the context ("9d ago") to
move an item within its range, never out of it. It also says so in the
duplicate, team-review, blocked-label and thumbs-down rules.

## Results

Pointwise strategy, all 36 items in `eval/ground_truth.yaml`, 3 trials each,
run on 2026-11-07. Gemini at low thinking, as in production (`RANK-11`);
Claude without thinking, OpenAI with `reasoning.effort: "none"`. Costs use list
prices on 2026-11-07: US$0.10 and US$0.50 per million input and output tokens
for both small models, US$0.75 and US$3.75 for `gemini-3.8-flash`.

- v5 lifts Claude by about 0.2 and OpenAI by about 0.12, nearly all of it in
  set B. Gemini is unchanged within run-to-run variation.
- The first draft of v5 told the model that items it can't act on "usually"
  score 0.35 or less. That pushed an old but important issue where a
  collaborator CC'd the developer (`dart-lang/sdk#31275`, ground truth 11) from
  0.35 to 0.12, and cost Gemini 0.04 on set A. The final text keeps such items
  in their 0.35–0.5 range.
- The v4 OpenAI run lost one item, which OpenAI's content filter refused as a
  false positive. The client now reports that as `blocked`, an item-level
  failure, instead of an unexpected error. It also now reads the last message
  of an answer that parses: `gpt-6-luna` sometimes sends a garbled draft as a
  first message.

## Caveats

- **Set B is no longer a clean held-out set for v5.** v5's rules were written
  after reading which items the small models got wrong, and most of those are
  in set B. The rules are general, not about specific items, but set B now
  overstates how much v5 helps. Labelling a fresh set of items would give a
  clean measure.
- One ranker, 36 items, and v4 was tuned against `gemini-3.8-flash`, which
  favours it. Differences of a few hundredths of tau are within run-to-run
  variation.
- Even with v5, both small models are about 0.12 below Gemini, at a fifth to a
  ninth of the cost per item.
