## Description
#352 moves `RetryRunner`, `ExponentialRetry`, and `ChecksumValidationException` into `package:google_cloud_rpc`, but the latest published `google_cloud_rpc` (0.6.0) doesn't include them. The workspace resolves the local copy, so CI won't catch that `google_cloud_storage` still allows `google_cloud_rpc: ^0.6.0`.

Once the generated `google_cloud_rpc` version has been bumped:

- [ ] Require the new version in `pkgs/google_cloud_storage/pubspec.yaml` (as #333 did for 0.6.0) and mention it in the CHANGELOG, before releasing `google_cloud_storage` 0.6.5.
- [ ] Do the same in `pkgs/google_cloud_pubsub/pubspec.yaml` before publishing `google_cloud_pubsub`, since it imports `package:google_cloud_rpc/retry.dart` from #353 on.
