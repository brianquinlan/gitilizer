## Description
## Summary
- `isWithin('/dir/.', '/dir/.file')` was false because the fast path matched the parent's trailing `.` against the first character of `.file`.
- A lone `.` component means the current directory, so `/dir/.` is the same directory as `/dir` and contains `/dir/.file`. A name such as `.bar` is unchanged.
- Covered with posix cases, and checked the same behavior on the Windows style.

Fixes #537
