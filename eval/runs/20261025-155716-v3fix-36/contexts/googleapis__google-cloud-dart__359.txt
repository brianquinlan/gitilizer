## Description
### Context & Problem

PR #352 extracts `RetryRunner`, `ExponentialRetry`, `NoDelayRetry`, and `defaultIsRetryable` into `package:google_cloud_rpc/retry.dart` (`keep:` list) so `google_cloud_storage` and `google_cloud_pubsub` (#353) can share a common retry implementation (#346).

However, three transport and codegen gaps remain before `RetryRunner` can reliably protect all 20+ generated REST client packages in `generated/*`:

1. **`ServiceClient._makeRequest()` Does Not Invoke `RetryRunner` or Accept `RequestOptions`**:
   - `ServiceClient._makeRequest()` in `generated/google_cloud_rpc/lib/service_client.dart` still executes raw `http.Client.send` calls without invoking `RetryRunner`, and provides no mechanism for callers to configure client-level retry policies, per-call timeouts, or custom headers (`RequestOptions`).
   - By contrast, sibling `sidekick`-generated SDKs (`google-cloud-rust` and `google-cloud-swift`) wrap every generated client transport in a `RetryLoop` consulting a client-level `RetryPolicy` and per-call `RequestOptions`.

2. **Bug: `ServiceException.fromHttpResponse` Throws `FormatException` on HTML `502`/`503`/`504` Responses (Bypassing `RetryRunner`)**:
   - In `generated/google_cloud_rpc/lib/src/exceptions.dart:60`, `ServiceException.fromHttpResponse(http.Response response, String body)` calls `JsonDecode(body)` whenever `body.isNotEmpty` without catching `FormatException`.
   - When a Google Front End (GFE) or load balancer returns a transient `502 Bad Gateway`, `503 Service Unavailable`, or `504 Gateway Timeout` with an HTML error page (`<html>...`), `JsonDecode(body)` throws an uncaught `FormatException` **before `ServiceException` is constructed**.
   - Because `defaultIsRetryable` in `retry.dart` (#352) checks `if (error is ServiceException)` (`500`, `502`, `503`, `504`, `408`, `429`), an uncaught `FormatException` completely bypasses `RetryRunner` on gateway errors.

<del>
3. **AIP-4222 `x-goog-request-params` Routing Headers & AIP-155 Auto-Populated `request_id` UUIDv4 (`sidekick/dart`)**:
   - `sidekick/api` (`routing_info.go`) already parses `google.api.routing` annotations into `api.Method.Routing` and `auto_populated_fields` (`request_id` UUIDv4) into `api.Method.AutoPopulated`, and `sidekick/rust` emits both, whereas `sidekick/dart` currently drops them.
   - Emitting `x-goog-request-params` is required by [AIP-4222](https://google.aip.dev/client-libraries/4222) for regional/tenant routing, and auto-populating empty `request_id` fields with a UUIDv4 ([AIP-155](https://google.aip.dev/155) / [AIP-4235](https://google.aip.dev/client-libraries/4235)) makes mutating `POST` RPCs idempotent so `RetryRunner` can safely retry them on transient failures.
</del>

### Proposed Solution

1. **Harden `ServiceException.fromHttpResponse` and Extend `ServiceClient` in `package:google_cloud_rpc`**:
   - Wrap `JsonDecode(body)` in `ServiceException.fromHttpResponse` (`exceptions.dart:60`) in a `try / on FormatException` block that falls back to constructing the status-code-mapped `ServiceException` with `response.reasonPhrase ?? body` when the error payload is non-JSON/HTML.
   - Add an optional `RetryRunner retry` parameter to `ServiceClient({...})` (defaulting to `const NoDelayRetry()` or per-service defaults passed by generated clients).
   - Add a `RequestOptions` class in `package:google_cloud_rpc` supporting per-call `Duration? timeout`, `RetryRunner? retry`, and `Map<String, String>? headers`.
   - Update `ServiceClient._makeRequest()` to execute requests through `(options?.retry ?? this.retry).run(...)` with optional timeout enforcement.
2. **Update `sidekick/dart` Generator Templates (`googleapis/librarian`)**:
   - Pass service-specific retry defaults (from service config / `librarian.yaml`) when constructing `ServiceClient`.
   - Add an optional `RequestOptions? options` parameter to generated RPC methods in `method.mustache`.

    Go:
    ```golang
    package main
    
    import (
    	"context"
    	"time"
    
    	secretmanager "cloud.google.com/go/secretmanager/apiv1"
    	"cloud.google.com/go/secretmanager/apiv1/secretmanagerpb"
    	"github.com/googleapis/gax-go/v2"
    	"google.golang.org/grpc/codes"
    )
    
    func example(ctx context.Context) error {
    	client, err := secretmanager.NewClient(ctx)
    	if err != nil {
    		return err
    	}
    	defer client.Close()
    
    	// 1. Client-level (per-method) override on CallOptions:
    	client.CallOptions.GetSecret = []gax.CallOption{
    		gax.WithRetry(func() gax.Retryer {
    			return gax.OnCodes([]codes.Code{
    				codes.Unavailable,
    				codes.DeadlineExceeded,
    			}, gax.Backoff{
    				Initial:    100 * time.Millisecond,
    				Max:        10 * time.Second,
    				Multiplier: 1.3,
    			})
    		}),
    	}
    
    	// 2. Per-call override via variadic gax.CallOption:
    	req := &secretmanagerpb.GetSecretRequest{Name: "projects/my-project/secrets/my-secret"}
    	secret, err := client.GetSecret(
    		ctx,
    		req,
    		gax.WithTimeout(30*time.Second),
    		gax.WithRetry(func() gax.Retryer {
    			// Return a fresh Retryer per call (Retryer is stateful)
    			return gax.OnHTTPCodes(gax.Backoff{
    				Initial:    500 * time.Millisecond,
    				Max:        30 * time.Second,
    				Multiplier: 2.0,
    			}, 429, 502, 503, 504)
    		}),
    	)
    	_ = secret
    	return err
    }
    ```
