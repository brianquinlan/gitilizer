## Description
Change the way that `librarian bump` works for dart:
1. expect that unpublished packages do *not* have a version in `librarian.yaml` (`librarian generate` will set the `pubspec.yaml` version to `default.dart.version`  or `0.1.0)
2. if `librarian bump` is run on an unpublished package then the `librarian.yaml` and `pubspec.yaml` versions are set to to `default.dart.version`  or `0.1.0

This is necessary because `librarian tag` finds the packages released by a commit by comparing the versions in `librarian.yaml` before and after `librarian bump`. New Dart packages were onboarded with a version already in librarian.yaml, so bump never changed it and `librarian tag` skipped their first release.

Fixes https://github.com/googleapis/google-cloud-dart/issues/358
