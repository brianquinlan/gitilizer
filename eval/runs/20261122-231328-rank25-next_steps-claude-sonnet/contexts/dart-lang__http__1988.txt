## Description
While I understand the [package's status](https://pub.dev/packages/ok_http#status-experimental) is still experimental, the last version on pub.dev was published 2 years ago, and it:

- does not support the latest dependencies, such as `jni` (fixed in #1943).
- has not migrated to use the built-in Kotlin yet (fixed in #1973).
- is not part of the `labs.dart.dev` publisher, even though the README suggests that it is.

I wonder whether there are plans to publish a new version with these recent changes, even if published as a pre-release.
