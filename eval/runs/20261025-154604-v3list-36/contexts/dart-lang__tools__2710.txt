## Description
> [!NOTE]
> This PR was generated by an AI coding agent (Jetski) on behalf of @mosuem.

Stacked on #2563. Extracts the SLSA provenance parsing and the package attestation policy that dart-lang/pub#4875 (`lib/src/sigstore/provenance.dart`, `verifier.dart`) and dart-lang/pub-dev#9546 (`app/lib/package/attestation_verifier.dart`) currently each carry a copy of into `package:sigstore/provenance.dart`, as proposed in https://github.com/dart-lang/pub-dev/pull/9546#issuecomment-6120956306.

The new library is pure Dart (`dart:convert` only, no `dart:ffi`, no new dependencies), so it can be imported on every platform, including from `pub`'s `sigstore_stub.dart` configuration:

- `GitHubRepository` (`tryParse`, `tryParseSlug`), `GitHubWorkflowIdentity` (`tryParse`), `ProvenanceSubject`
- `BuildProvenance.parseBundle` — the union of both copies: pub-dev's `repositoryId`, `repositoryOwnerId` and `runUrl` included
- `TransparencyLogEntry.tryParseBundle`
- `checkProvenancePolicy` — the union of both signatures: `expectedRepository`, `configuredRepository` (pub-dev's `configuredGitHubRepository`), `declaredPackageName`/`declaredPackageVersion` (pub), `requireRepository`, `requireTaggedSignerRef`

Two deliberate differences from the copies:

- `packageVersion` / `declaredPackageVersion` are `String`s, so `package:sigstore` does not pick up a `pub_semver` dependency. Callers pass `version.toString()`.
- `trustedSignerWorkflows` is required and has no default: which workflows are trusted to sign is the consumer's policy, and `pub.dev` should be able to change it without a `package:sigstore` release. (`defaultTrustedSignerWorkflows` stays in `pub` and `pub.dev`.)

The sha256-mismatch message is now neutral (`but this archive has sha256 ...`) instead of `downloaded` (pub) / `uploaded` (pub-dev).

Tests: `provenance_test.dart` and `policy_test.dart` move over from pub#4875, extended for `tryParseSlug`, the repository ids / run url, `TransparencyLogEntry`, `configuredRepository` and `declaredPackage*`. `sigstore_test.dart` gains an end-to-end test that verifies the real `helpful 0.1.5` attestation over the archive digest (`isDigest: true`) through the native bindings and then feeds `verifiedIdentity()` into `GitHubWorkflowIdentity.tryParse` and `checkProvenancePolicy`, which pins the identity format the parser must understand to the one the bindings produce.

Follow-ups once this is released: switch dart-lang/pub#4875 and dart-lang/pub-dev#9546 to import `package:sigstore/provenance.dart` and delete their copies.
