## Description
Worked around a [cronet bug](https://issues.chromium.org/issues/406926302) where multiple packages have the same. See the comment in pkgs/cronet_http/android/build.gradle for details.

Also upgrades `package:jnigen` to `1.0.1` to avoid a CI failure because the CI would version solve against `package:jnigen` `1.0.1`, which generates slightly different code to `1.0.0`.

Fixes https://github.com/dart-lang/http/issues/1932
