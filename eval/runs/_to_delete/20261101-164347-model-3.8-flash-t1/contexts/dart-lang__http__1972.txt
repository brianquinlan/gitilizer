## Description
It looks like the HTTP implementation is receiving the Content-Length and then performing its usual body-length consistency check without correctly accounting for the fact that the request was HEAD.

The HEAD call itself is fine and gives an 200 OK, but trying to do anything around a try/catch setup gets messed up by this unexpected ClientException.
