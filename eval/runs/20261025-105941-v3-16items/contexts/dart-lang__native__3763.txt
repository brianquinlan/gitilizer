## Description
## Description

The `NSInputStream` returned by `toNSInputStream` currently ignores [`scheduleInRunLoop:forMode:`](https://github.com/dart-lang/native/blob/3cbe319e3c1ec0f9253c126ba3e465e55229c3a4/pkgs/objective_c/src/input_stream_adapter.m#L66-L67).

This causes `NSURLSession` to make [read:maxLength](https://github.com/dart-lang/native/blob/3cbe319e3c1ec0f9253c126ba3e465e55229c3a4/pkgs/objective_c/src/input_stream_adapter.m#L131) calls on its single, process-wide `com.apple.NSURLConnectionLoader thread`, which [waits](https://github.com/dart-lang/native/blob/3cbe319e3c1ec0f9253c126ba3e465e55229c3a4/pkgs/objective_c/src/input_stream_adapter.m#L163) until the Dart stream provides data. This really hurts `package:cupertino_http`'s performance when performing concurrent uploads.
