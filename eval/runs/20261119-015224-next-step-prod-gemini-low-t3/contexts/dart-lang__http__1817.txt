## Description
Just wanted to let you know that this issue is still present on android devices: https://github.com/dart-lang/http/issues/877

I discovered the problem while using the openid_client (https://pub.dev/packages/openid_client).
I configured the authentication process to use an external browsers (See https://github.com/appsup-dart/openid_client/issues/128 for more details) and this is what happens:

- When the authentication process starts the App goes in background and open a browser to desired authentication server URL
- When you log in the browser will be redirected to localhost:4000 with all the relevant data
- However the openUrl on https://github.com/dart-lang/http/blob/ef05b3744424885d93f88a6a50664fb5b7d5cbdb/pkgs/http/lib/src/io_client.dart#L114 fails with the "ClientException with SocketException: Failed host lookup: 'xxx.yyy.zzz' (OS Error: No address associated with hostname, errno = 7)" since the App has been put on background (and the browser is still on foreground)

If you use an inApp webview the problem doesn't occur (since the app is still on foreground)
