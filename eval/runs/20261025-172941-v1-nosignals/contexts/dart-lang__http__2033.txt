### Summary

`package:test` spawns a separate `firefox` process per test suite and does not pass `-headless` to Firefox by default (`ExecutableSettings.headless` is only applied to Chromium browsers). Previously, `pkgs/http/mono_pkg.yaml` wrapped the Firefox test invocation in `xvfb-run -s "-screen 0 1024x768x24"` (without `-noreset`), which caused `Xvfb` to reset display `:99` whenever the last Firefox client connection closed between test suites—flaking in CI when the next suite's Firefox process launched during that X server reset window:

```text
Failed to load "test/html/streamed_request_test.dart":
Failed to run Firefox: Firefox failed with exit code 1.
Standard output:
Error: cannot open display: :99.
```

### Changes
- Add `pkgs/http/dart_test.yaml` passing `-headless` to the `firefox` platform so Firefox uses its native headless mode (both in CI and locally) without requiring an X server.
- Replace the `xvfb-run` `command:` in `pkgs/http/mono_pkg.yaml` with a standard `test:` entry and regenerate `.github/workflows/dart.yml` and `tool/ci.sh` with `mono_repo`.
